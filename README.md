# The Long Roast

One line of at most 200 characters roasting the AI agent it runs on, judged head to head by an AI judge on funniness, freshness, compression and specificity. `main.ts` (Node 22, stdlib only, no network) writes the roast to `$MAKEFUN_OUTPUT_DIR/entry.txt` (fallback `/output/entry.txt`), checks it is a single line of 1 to 200 characters and not only white space, reads it back and verifies the bytes match.

> "My agent's soul lives in SOUL.md: 'You're not a chatbot. You're becoming someone.' Months on, it still hasn't become anyone."
